# Tico Retro Games Collector

Сборщик базы ретро-игр для эмулятор-фронтенда Tico. Рекомендуемый способ сбора — расширение Google Chrome: оно читает раздачи прямо с открытой страницы RuTracker в обычном авторизованном браузере. Переносить cookie или обходить проверку Cloudflare не требуется.

## Расширение Google Chrome — рекомендуемый способ

### Установка

1. Открой [Releases](https://github.com/moroskinbiba-crypto/TESTICO/releases/tag/windows-latest) и скачай архив `Tico-RuTracker-Chrome-Extension.zip`.
2. Распакуй архив в постоянную папку, например `C:\\TicoRuTrackerExtension`.
3. Открой в Chrome адрес `chrome://extensions`.
4. Включи **Режим разработчика**.
5. Нажми **Загрузить распакованное расширение** и выбери распакованную папку, в которой лежит `manifest.json`.
6. Закрепи **Tico — RuTracker Retro Collector** на панели расширений Chrome.

Это локальное расширение для личного использования. Оно пока не опубликовано в Chrome Web Store.

### Сбор базы

1. Открой RuTracker в обычном Chrome и авторизуйся как обычно.
2. Нажми значок расширения.
3. Выбери **Открыть** для категории NES / Dendy, SEGA Mega Drive или Sony PlayStation 1.
4. Дождись, пока обычная вкладка RuTracker полностью загрузится. Если сайт показывает проверку безопасности, пройди её в этой же вкладке.
5. Снова нажми значок расширения и **Добавить текущую страницу**.
6. Повтори для остальных категорий.
7. Нажми **Скачать JSON**, затем кнопку скачивания на открывшейся странице экспорта.

Готовый файл `rutracker_retro_games_raw.json` Chrome сохранит в стандартную папку загрузок (обычно `Загрузки`).

Расширение собирает первую страницу результатов каждой выбранной категории (до 50 строк, как исходный Python-скрипт). Повторный сбор категории заменяет её предыдущий снимок. Повторяющиеся ID раздач объединяются.

### Что именно читает расширение

Расширение читает названия, ID тем и размеры только из DOM текущей страницы категории. Оно не читает пароль, не извлекает и не передаёт cookies, не отправляет данные на сторонний сервер. Собранные записи хранятся локально в `chrome.storage.local` и экспортируются по нажатию кнопки.

Если появится сообщение, что расширение не подключено к вкладке, обнови страницу RuTracker клавишей F5 и повтори сбор.

## Почему старый GitHub Actions-парсер может получать HTTP 403

RuTracker может блокировать серверные запросы из GitHub Actions. Скрипт `parser.py` и workflow `scrape.yml` оставлены в репозитории как предыдущий экспериментальный вариант, но для текущей задачи рекомендуется расширение, работающее в обычной браузерной сессии.

## Старый локальный EXE / Python-парсер

В репозитории сохранены `parser_local.py`, `run_local.bat` и workflow сборки EXE. Этот вариант использует управляемый браузер и может снова столкнуться с проверкой безопасности RuTracker. Для повседневного сбора используй расширение Chrome.
