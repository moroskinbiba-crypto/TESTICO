# Tico — RuTracker Page Fingerprinter

Расширение Chrome для сбора каталога игровых раздач RuTracker из страниц, которые пользователь открывает в обычной браузерной сессии.

## Установка

1. Открой [Releases](https://github.com/moroskinbiba-crypto/TESTICO/releases/tag/windows-latest) и скачай \`Tico-RuTracker-Chrome-Extension.zip\`.
2. Распакуй архив в постоянную папку.
3. Открой \`chrome://extensions\`.
4. Включи **Режим разработчика**.
5. Нажми **Загрузить распакованное расширение** и выбери папку с \`manifest.json\`.
6. Закрепи расширение **Tico — RuTracker Page Fingerprinter** на панели Chrome.

Если расширение уже установлено, обнови содержимое папки и нажми кнопку перезагрузки на его карточке.

## Сбор страниц

1. Открой RuTracker в обычном Chrome и авторизуйся как обычно.
2. Оставь **Автосбор: ВКЛ**.
3. Пройди все страницы списков категорий. Каждая открытая страница \`tracker.php\` сохранит отпечаток разметки, пагинацию, ID и названия видимых тем, размеры и сиды/личи (если они есть в таблице).
4. Открой сами темы раздач \`viewtopic.php?t=...\`. На них расширение сохранит magnet-ссылки, ссылки \`.torrent\` и типовые RuTracker-адреса \`dl.php\` / \`download.php\`.
5. Нажми **Экспорт JSON**.

## Содержимое JSON

Экспортируется файл \`tico_rutracker_page_fingerprints.json\`:
- \`topics\` — объединённый каталог тем с ID, заголовком, категорией, размером и найденными ссылками скачивания;
- \`download_links\` — отдельный плоский список уникальных magnet- и torrent-ссылок, связанный с ID темы;
- \`page_fingerprints\` — отпечатки страниц: DOM-селекторы, классы и ID, структура таблиц, метаданные и пагинация;
- \`summary\` — статистика сбора.

Для magnet извлекается infohash, если он есть в URI. Ссылки \`dl.php\` сохраняются как адреса RuTracker и могут требовать авторизации в браузере. Расширение только записывает адреса и не нажимает на них, не запускает скачивание и не передаёт данные на сервер.

## Ограничения и приватность

- Расширение обрабатывает только страницы, открытые пользователем в обычном Chrome. Оно не автоматизирует обход Cloudflare и не делает фоновых запросов к RuTracker.
- В списках категорий видны темы, но сами ссылки скачивания обычно находятся на страницах отдельных тем. Поэтому, чтобы собрать ссылки, нужно открывать также страницы раздач.
- Сбор хранится в \`chrome.storage.local\` на компьютере. Пароли и cookies не читаются и не экспортируются.
- Перед сохранением из URL удаляются распространённые параметры сессии и авторизации.
- Повторное посещение обновляет отпечаток той же страницы, а не создаёт новый дубликат.

Проверка GitHub Actions подтверждает синтаксис и упаковку расширения. Реальную работу извлечения на RuTracker нужно проверить в открытой авторизованной сессии браузера.
