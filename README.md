# Tico Retro Games Collector

Сборщик базы консольных игр для эмулятор-фронтенда Tico. Рекомендуемый способ сбора — расширение Google Chrome: оно читает раздачи прямо с открытой страницы RuTracker в обычном авторизованном браузере.

## Расширение Google Chrome

### Установка

1. Открой [Releases](https://github.com/moroskinbiba-crypto/TESTICO/releases/tag/windows-latest) и скачай архив `Tico-RuTracker-Chrome-Extension.zip`.
2. Распакуй архив в постоянную папку, например `C:\\TicoRuTrackerExtension`.
3. Открой в Chrome адрес `chrome://extensions`.
4. Включи **Режим разработчика**.
5. Нажми **Загрузить распакованное расширение** и выбери распакованную папку, в которой лежит `manifest.json`.
6. Закрепи **Tico — RuTracker Retro Collector** на панели Chrome.

### Сбор базы

1. Открой RuTracker в обычном Chrome и авторизуйся как обычно.
2. Нажми значок расширения и выбери нужную категорию.
3. Дождись, пока страница категории полностью загрузится.
4. Снова нажми значок расширения и **Добавить текущую страницу**.
5. Повтори для остальных нужных категорий.
6. Нажми **Скачать JSON**, затем кнопку скачивания на открывшейся странице экспорта.

Файл `rutracker_retro_games_raw.json` Chrome сохранит в стандартную папку загрузок (обычно `Загрузки`).

Расширение читает названия, ID тем и размеры только из DOM текущей страницы. Оно не читает пароль, не извлекает и не передаёт cookies, не отправляет данные на сторонний сервер. Собранные записи хранятся локально в `chrome.storage.local`.

По умолчанию собирается первая страница результатов каждой категории (до 50 строк). Повторный сбор категории заменяет её предыдущий снимок. Повторяющиеся ID раздач объединяются.

Если расширение не подключилось к вкладке, обнови страницу RuTracker клавишей F5 и повтори сбор.

## Старый вариант

В репозитории остаются `parser.py`, `parser_local.py` и Windows EXE. Они были экспериментом с Playwright/GitHub Actions и не рекомендуются для сбора, поскольку RuTracker может показывать автоматизированному браузеру проверку безопасности.
