# Tico — RuTracker Page Fingerprinter

Расширение Chrome для сбора каталога игровых раздач RuTracker из страниц, которые пользователь открывает в обычной браузерной сессии.

## Установка

1. Открой [Releases](https://github.com/moroskinbiba-crypto/TESTICO/releases/tag/windows-latest) и скачай \`Tico-RuTracker-Chrome-Extension.zip\`.
2. Распакуй архив в постоянную папку.
3. Открой \`chrome://extensions\`, включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери папку с \`manifest.json\`.
5. Закрепи расширение на панели Chrome.

Если расширение уже установлено, обнови файлы в папке и нажми кнопку перезагрузки на его карточке.

## Сбор

1. Открой RuTracker в обычном Chrome и авторизуйся как обычно.
2. Оставь автосбор включённым.
3. Открывай страницы списков категорий и переходи по пагинации. В правом нижнем углу каждой страницы появится зелёное сообщение о сохранении.
4. Для ссылок скачивания открывай страницы самих тем. Расширение сохранит magnet, адреса \`.torrent\`, \`dl.php\` и \`download.php\`, если они присутствуют в разметке.
5. Нажми **Экспорт JSON**.

Категории: PS (908), PS2 (357), PS1/PSP (1116), Wii U/Wii/GameCube (773), 3DS/DS (774), Dreamcast (968), остальные консоли (129).

## JSON

Экспортируется \`tico_rutracker_page_fingerprints.json\`:
- \`topics\` — объединённый каталог тем;
- \`download_links\` — отдельный список найденных magnet и torrent URL;
- \`page_fingerprints\` — структурные отпечатки HTML, таблиц, классов, селекторов и полей;
- \`summary\` — статистика.

Расширение не запускает скачивание, не читает пароль/cookies и не отправляет собранные данные на сервер. Ссылки остаются локально в Chrome. Из URL удаляются типовые параметры сессии.

Если зелёное сообщение не появилось, открой popup расширения: там показывается последняя ошибка. Также обнови вкладку RuTracker после обновления расширения (F5), чтобы браузер загрузил новый content script.

Проверка GitHub Actions подтверждает синтаксис и упаковку. Реальное извлечение ссылок требует проверки на открытой странице RuTracker.
